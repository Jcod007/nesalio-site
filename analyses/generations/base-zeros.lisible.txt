TITRE : Trouver les zéros de f(x) = −(x − 2)² + 3
=== Tranche s_idee
  OBJET def_zero [text] "Un zéro : une entrée x qui donne une sortie f(x) = 0" 
  OBJET eq_depart [math] "-(x - 2)^2 + 3 = 0" parts=-(x - 2)^2 | + 3 | = 0
DIT (questce) : Un zéro de la fonction, c'est une valeur de x qui rend f de x égal à zéro.
    show def_zero @cue:c_zero 
DIT (partir) : Chercher les zéros, c'est donc résoudre l'équation moins, parenthèse, x moins deux, au carré, plus trois, égale zéro.
    dim def_zero @beat:start 
    write eq_depart @cue:c_eq {"part":"carre"}
    write eq_depart @after:w_carre {"part":"plus3"}
    write eq_depart @after:w_plus3 {"part":"zero"}
=== Tranche s_isoler
  OBJET etape2 [math] "-(x - 2)^2 = -3" 
  OBJET etape3 [math] "(x - 2)^2 = 3" 
DIT (enleve3) : On retire trois des deux côtés pour garder l'égalité : moins, x moins deux, au carré, égale moins trois.
    transform etape2 @cue:c_retire {"source":"eq_depart"}
    highlight etape2 @cue:c_egale {"role":"accent"}
DIT (divise) : Ensuite, on divise les deux côtés par moins un : le carré reste seul, il égale trois.
    transform etape3 @cue:c_divise {"source":"etape2"}
    highlight etape3 @cue:c_trois {"role":"result"}
=== Tranche s_verif
  OBJET verif [math] "(x - 2)^2 = 3 \\iff x - 2 = \\pm\\sqrt{3}" 
  OBJET zero1 [point] {"at":[0.27,0]}   <<JAMAIS MONTRÉ>>
  OBJET zero2 [point] {"at":[3.73,0]}   <<JAMAIS MONTRÉ>>
  OBJET lbl1 [label] "(0,27 ; 0)" attaché à zero1   <<JAMAIS MONTRÉ>>
  OBJET lbl2 [label] "(3,73 ; 0)" attaché à zero2   <<JAMAIS MONTRÉ>>
  OBJET axe [number_line] {"domain":[-1,5]}   <<JAMAIS MONTRÉ>>
DIT (racine) : Un carré égal à trois, ça veut dire que x moins deux vaut racine de trois, ou moins racine de trois.
    transform verif @cue:c_racine {"source":"etape3"}
    highlight verif @cue:c_moins {"role":"accent"}
DIT (isoler) : On isole x : x égale deux plus racine de trois, ou deux moins racine de trois.
    highlight verif @cue:c_plus {"role":"result"}
