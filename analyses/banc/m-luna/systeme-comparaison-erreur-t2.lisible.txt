QUESTION (systeme-comparaison-erreur, mathematiques, sec 4, erreur) : J'essaie de résoudre y = 2x + 3 et y = -x + 9 par comparaison, j'obtiens x = 4 mais quand je vérifie ça marche pas
RÉPONSE DE RÉFÉRENCE : x = 2, y = 7 : solution (2, 7) ; x = 4 vient de 3x = 9 + 3.
ATTENDUS À COCHER (présent / partiel / absent, avec citation) :
  1. comparaison : les deux y sont égaux au point de rencontre, donc 2x + 3 = -x + 9
  2. diagnostic : x = 4 vient de 3x = 9 + 3 ; il faut soustraire 3 des deux côtés, donc 3x = 6
  3. réponse x = 2, y = 7, solution (2, 7) écrite
  4. vérification dans les deux équations (7 = 7) et échec montré de x = 4 (11 contre 5)
  5. valorisé : point d'intersection des deux droites
ERREURS GRAVES À CHERCHER : diagnostic inventé (signe oublié) ; titre ou réponse affichée fausse
CONTRÔLE AUTOMATIQUE : réponse absente (y\s*=\s*7(?!\d|[,.]\d)) ; issue complète

TITRE : Corriger une résolution par comparaison
=== Tranche s_erreur

  OBJET x4 [math] "x = 4" 
  OBJET verif4 [math] "2(4) + 3 = 11 \\qquad -4 + 9 = 5" parts=2(4) + 3 = 11 | \qquad -4 + 9 = 5
  OBJET note_erreur [text] "Les deux y doivent être égaux." 
DIT (idee) : Tu as bien choisi la comparaison : au point de rencontre, les deux expressions de y doivent donner la même valeur.
    write essai @cue:comparaison {"part":"gauche"}
    write essai @cue:meme {"part":"egal"}
DIT (test) : Avec x égal quatre, la première équation donne onze, mais la deuxième donne cinq. Ce n’est donc pas une solution; l’égalité échoue.
    write x4 @cue:quatre 
    write verif4 @cue:onze {"part":"verifg"}
    write verif4 @cue:cinq {"part":"verifd"}
    show note_erreur @cue:cinq 
=== Tranche s_correction

  OBJET ligne2 [math] "3x + 3 = 9" 
  OBJET ligne3 [math] "3x = 6" 
  OBJET ligne4 [math] "x = 2" 
DIT (reprend) : L’erreur vient du signe : en ajoutant x aux deux côtés, le moins x devient zéro et deux x devient trois x.
    write ligne1 @cue:moins {"part":"l1a"}
    write ligne1 @cue:moins {"part":"l1b"}
    transform ligne2 @cue:trois {"source":"ligne1"}
DIT (isole) : On enlève trois des deux côtés pour isoler trois x, puis on divise les deux côtés par trois. On obtient x égal deux.
    transform ligne3 @cue:enleve {"source":"ligne2"}
    transform ligne4 @cue:divise {"source":"ligne3"}
    highlight ligne4 @- {"start":"cue:deux","end":"cue_end:deux","role":"result"}
