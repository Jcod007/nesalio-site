TITRE : Pourquoi on divise par P(B) dans une probabilité conditionnelle
=== Tranche s_part
  OBJET univ [polygon] {"vertices":[[0,0],[6,0],[6,4],[0,4]]} 
  OBJET b_zone [polygon] {"vertices":[[0,0],[3,0],[3,2],[0,2]]} 
  OBJET a_zone [polygon] {"vertices":[[0,0],[1,0],[1,1],[0,1]]}   <<JAMAIS MONTRÉ>>
  OBJET note [text] "l'univers entier a une surface de 1" attaché à univ
DIT (univers) : Imagine que toutes les issues possibles forment ce grand carré, dont l'aire vaut un. C'est tout l'univers des possibles.
    draw univ @cue:carre 
    show note @cue:aire 
DIT (evenement) : L'événement B, c'est une partie de ce carré : ici, sa zone à gauche vaut zéro virgule trois.
    show b_zone @cue:partie 
    highlight b_zone @cue:trois {"role":"accent"}
DIT (sachant) : Quand on dit « sachant B », on jette tout le reste : on ne regarde plus que cette zone-là.
    dim univ @cue:sachant_b 
    camera.focus  @cue:zone {"targets":["b_zone"],"bounds":"layout_bounds"}
=== Tranche s_renorm
  OBJET b_avant [math] "\\text{aire de } B = 0{,}3" 
  OBJET b_apres [math] "\\text{aire de } B = 1" 
DIT (probleme) : Mais là, il y a un problème : la zone de B ne vaut plus un, elle vaut zéro virgule trois au départ.
    write b_avant @cue:zero_trois 
DIT (renorm) : Pour en refaire un univers complet, on la remet à l'échelle : on divise par sa propre aire, par la probabilité de B.
    fade_out b_avant @cue:divise 
    write b_apres @cue:proba_b 
    highlight b_apres @after:w_apres {"role":"result"}
=== Tranche s_fraction
  OBJET a_dans_b [math] "\\text{aire de } A \\text{ dans } B = 0{,}1" 
  OBJET formule [math] "P(A \\mid B) = \\frac{P(A \\cap B)}{P(B)}" 
DIT (part_de_a) : Maintenant, la part de A qui se trouve dans B a une aire de zéro virgule un.
    write a_dans_b @cue:aire_a 
DIT (rapport) : La probabilité conditionnelle, c'est simplement ce rapport : la part des deux divisée par la part de B.
    write formule @cue:rapport_mot 
    highlight formule @cue:part_deux {"role":"accent"}
    highlight formule @cue:part_b {"role":"accent"}
DIT (calcul) : Ici : zéro virgule un divisé par zéro virgule trois donne environ zéro virgule trente-trois.
    highlight formule @cue:calc_mot {"role":"accent"}
    highlight formule @cue:resultat {"role":"result"}
=== Tranche s_retenir
DIT (idee) : À retenir : diviser par la probabilité de B, c'est juste remettre B à l'échelle pour qu'elle redevienne un univers complet.
    camera.focus  @cue:retenir {"targets":["formule"]}
    highlight formule @cue:remettre {"role":"result"}
