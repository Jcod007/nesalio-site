QUESTION (chimie-kc, chimie, sec 5, methode) : c'est quoi Kc pis comment je le calcule pour H2 + I2 ⇌ 2 HI si à l'équilibre [H2] = 0,10 mol/L, [I2] = 0,10 mol/L pis [HI] = 0,70 mol/L?
RÉPONSE DE RÉFÉRENCE : Kc = [HI]² / ([H₂][I₂]) = 0,49 / 0,010 = 49.
ATTENDUS À COCHER (présent / partiel / absent, avec citation) :
  1. à l'équilibre, les réactions directe et inverse ont la même vitesse ; les concentrations restent constantes
  2. Kc = [produits]^coefficients / [réactifs]^coefficients : [HI]² / ([H₂][I₂])
  3. le coefficient 2 devient un exposant : 0,70² = 0,49
  4. Kc = 0,49 / (0,10 × 0,10) = 49 écrit
  5. interprétation : Kc > 1, les produits sont favorisés
ERREURS GRAVES À CHERCHER : coefficient 2 multiplié au lieu d'être un exposant (Kc = 140) ; Kc inversé
