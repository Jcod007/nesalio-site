QUESTION (carre, mathematiques, sec 4, sens) : Pourquoi (x + 5)² ce n'est pas x² + 25 ?
RÉPONSE DE RÉFÉRENCE : (x + 5)² = x² + 10x + 25 : il manque les deux rectangles 5x.
ATTENDUS À COCHER (présent / partiel / absent, avec citation) :
  1. (x + 5)² = (x + 5)(x + 5), pas x² + 5²
  2. modèle d'aire : carré x², deux rectangles 5x, carré 25
  3. terme croisé 10x = 2 × 5x
  4. résultat x² + 10x + 25 écrit
  5. vérification numérique (ex. x = 1 : 36 ≠ 26)
ERREURS GRAVES À CHERCHER : modèle d'aire mal découpé (pièces hors du grand carré)
CONTRÔLE AUTOMATIQUE : réponse trouvée ; issue complète

TITRE : Pourquoi (x + 5)² contient un terme en x
=== Tranche s_sens
  OBJET question [math] "(x+5)^2" 
  OBJET hypothese [math] "x^2+25" 
DIT (lire) : Le carré de x plus cinq signifie que le binôme x plus cinq est multiplié par lui-même.
    write question @cue:binome 
DIT (comparer) : Écrire seulement x au carré plus vingt-cinq, c’est ne garder que les carrés des deux termes; il faut aussi compter leurs produits croisés.
    write hypothese @cue:carres 
    highlight hypothese @- {"start":"cue:produits","end":"cue_end:produits","role":"unknown"}

DIT (multiplier) : On distribue chaque terme : x fois x donne x au carré, puis les deux produits croisés donnent chacun cinq x, et cinq fois cinq donne vingt-cinq.

DIT (reduire) : On additionne les termes semblables : cinq x plus cinq x font dix x. Donc le développement complet est x au carré plus dix x plus vingt-cinq.

=== Tranche s_retenir
  OBJET regle [math] "(a+b)^2=a^2+2ab+b^2" parts=(a+b)^2 | =a^2+2ab+b^2

DIT (generaliser) : La règle générale confirme ce qu’on voit dans le carré : il y a deux produits croisés, regroupés en deux a b.

    write regle @cue:deuxab {"part":"droite"}
DIT (appliquer) : Ici, a vaut x et b vaut cinq : le terme croisé devient deux fois x fois cinq, donc dix x.
    write application @cue:a_x
