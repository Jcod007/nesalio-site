TITRE : Comparer deux droites : trouver x = 3
=== Tranche s_pose
  OBJET sys [math] "2x + 3 = -x + 9" parts=2x + 3 | = | -x + 9
  OBJET d1 [math] "y = 2x + 3" 
  OBJET d2 [math] "y = -x + 9" 
DIT (intro) : Bonne nouvelle : c'est la bonne méthode. Le problème, c'est un signe au moment de distribuer.
    show d1 @cue:bonne 
    show d2 @after:s1 
DIT (comp) : Par comparaison, on pose les deux membres égaux : deux x plus trois égale moins x plus neuf.
    write sys @cue:egaux 
    highlight sys @cue:deuxx {"part":"g"}
=== Tranche s_resolution
  OBJET et1 [math] "2x + x = 9 - 3" 
  OBJET et2 [math] "3x = 6" 
  OBJET et3 [math] "x = 2" parts=x | = 2
DIT (enleve) : On enlève le moins x des deux côtés : en l'ajoutant, deux x plus x donne trois x, et neuf moins trois donne six.
    transform et1 @cue:enleve {"source":"sys"}
    transform et2 @cue:troisx {"source":"et1"}
DIT (isole) : On divise les deux côtés par trois, et on obtient x égale deux.
    transform et3 @cue:diviser {"source":"et2"}
    highlight et3 @cue:xdeux {"role":"result","part":"deux"}
=== Tranche s_verif
  OBJET chk [math] "2(2) + 3 = 7" 
  OBJET chk2 [math] "-(2) + 9 = 7" 
  OBJET concl [callout] "Les deux droites se croisent en (2 ; 7)." 
DIT (verif) : Vérifions dans les deux équations. Dans la première : deux fois deux plus trois, ça donne sept.
    fade_out d1 @beat:start 
    write chk @cue:premiere 
    highlight chk @cue:sept {"role":"result"}
DIT (verif2) : Dans la deuxième : moins deux plus neuf, ça donne sept aussi. Les deux y sont égaux : c'est cohérent.
    fade_out d2 @cue:deuxieme 
    write chk2 @cue:deuxieme 
    highlight chk2 @cue:aussi {"role":"result"}
DIT (fini) : Donc la solution est le point (deux ; sept) : les deux droites s'y croisent.
    show concl @cue:point 
=== Tranche s_retenir
  OBJET regle [math] "y = 2x + 3 = -x + 9" 
  OBJET note [text] "Toujours distribuer AVEC les signes" 
DIT (err) : Ton erreur venait d'un signe oublié : quand on élimine moins x, on l'ajoute des deux côtés, il devient plus x.
    fade_out chk @cue:erreur 
    fade_out chk2 @cue:erreur 
    fade_out concl @cue:erreur 
    write regle @cue:plus 
    highlight regle @after:s_regle {"role":"accent"}
DIT (ret) : À retenir : par comparaison, on égalise, on isole x avec la bonne opération des deux côtés, puis on vérifie dans les équations de départ.
    show note @cue:retenir 
    highlight et3 @cue:verifie {"role":"result"}
