TRANCHE 1 — partir du concret : enrouler un rayon sur le cercle
DIT : Dessine un cercle, prends son rayon, et enroule ce rayon le long du cercle, comme une ficelle.

DIT : L'angle au centre qui correspond à cet arc, c'est exactement un radian.
TABLEAU : arc rouge surligné ; flèche partant du centre vers les deux extrémités de l'arc, étiquette « 1 radian ».
DIT : Un radian n'est pas une unité inventée : c'est un rapport entre deux longueurs, donc un nombre pur, sans dimension.
TABLEAU : encadré : $1\ \text{rad} = \dfrac{\text{longueur d'arc}}{\text{rayon}}$.

TRANCHE 2 — le tour complet et la conversion
DIT : La circonférence d'un cercle de rayon r vaut deux pi r.
TABLEAU : formule encadrée : $C = 2\pi r$.
DIT : Donc en radians, le tour complet vaut la circonférence divisée par le rayon, c'est-à-dire deux pi.
TABLEAU : $C/r = 2\pi r / r = 2\pi$ ; encadré : $360° = 2\pi\ \text{rad}$.
DIT : Pour convertir, on multiplie par pi sur 180 : par exemple 180 degrés donnent pi radians.
TABLEAU : $\text{degrés} \times \dfrac{\pi}{180} = \text{radians}$ ; exemple : $180 \times \pi/180 = \pi$.
DIT : Et dans l'autre sens, 90 degrés donnent pi sur deux, soit environ 1,57 radian.
TABLEAU : $90 \times \pi/180 = \pi/2 \approx 1{,}57\ \text{rad}$.

TRANCHE 3 — pourquoi les radians simplifient tout
DIT : Voici la formule de la longueur d'arc quand l'angle est en degrés : L égale pi r theta sur 180.
TABLEAU : formule encadrée : $L = \dfrac{\pi r \theta}{180}$ avec « θ en degrés ».
DIT : Maintenant, si theta est en radians, le 180 disparaît : L égale r fois theta.
TABLEAU : transformer la formule : barrer le 180 et le π ; encadré : $L = r\theta$ avec « θ en radians ».
DIT : Même chose pour la dérivée de sinus : en radians, sinus prime x égale cosinus x, sans facteur correctif.
TABLEAU : encadré : $(\sin x)' = \cos x$ ; note « valable seulement si x est en radians ».
DIT : En degrés, il faudrait traîner un facteur pi sur 180 partout, ce qui alourdit chaque formule.
TABLEAU : $(\sin x°)' = \dfrac{\pi}{180}\cos x°$ en petit, à côté de la version radians surlignée.

TRANCHE 4 — vérification sur un exemple concret
DIT : Reprenons le cercle de rayon 3, et un angle d'un demi-tour, donc pi radians.
TABLEAU : cercle de rayon 3 ; arc allant d'un bout à l'autre du cercle (demi-circonférence).
DIT : La longueur d'arc vaut r theta, donc 3 fois pi, environ 9,42.
TABLEAU : $L = 3 \times \pi \approx 9{,}42$ ; l'arc est étiqueté « L ≈ 9,42 ».
DIT : Vérifions avec la vraie formule : la demi-circonférence vaut pi fois r, donc 3 pi.
TABLEAU : $C/2 = 2\pi r/2 = \pi r = 3\pi \approx 9{,}42$ — même résultat.
DIT : Avec la version en degrés, 180 degrés, on aurait L égale pi fois 3 fois 180 sur 180, ce qui redonne 3 pi, mais au prix d'un calcul inutile.
TABLEAU : $L = \pi \cdot 3 \cdot 180/180 = 3\pi$ ; les 180 se simplifient.
DIT : Conclusion : le radian mesure l'angle par la longueur d'arc, et c'est ce qui rend les formules courtes.
