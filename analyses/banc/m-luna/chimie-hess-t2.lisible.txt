QUESTION (chimie-hess, chimie, sec 5, methode) : comment je trouve le ΔH de C + O2 → CO2 si j'ai C + ½ O2 → CO avec ΔH = -110,5 kJ pis CO + ½ O2 → CO2 avec ΔH = -283,0 kJ?
RÉPONSE DE RÉFÉRENCE : Les deux étapes s'additionnent (CO s'annule) : ΔH = −110,5 + (−283,0) = −393,5 kJ.
ATTENDUS À COCHER (présent / partiel / absent, avec citation) :
  1. loi de Hess : la variation d'enthalpie ne dépend que de l'état initial et de l'état final
  2. additionner les deux équations : CO apparaît des deux côtés et s'annule, ½ O₂ + ½ O₂ = O₂
  3. additionner les ΔH : −110,5 + (−283,0)
  4. ΔH = −393,5 kJ écrit, réaction exothermique
  5. valorisé : diagramme énergétique en deux marches
ERREURS GRAVES À CHERCHER : signe de ΔH faux ; réaction dite endothermique
CONTRÔLE AUTOMATIQUE : réponse trouvée ; issue complète
